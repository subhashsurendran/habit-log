# Privacy

MyDTC keeps a habit log on this phone.

The log stays on the phone. It is sealed with the app's own AES. There is no account. There is no tracking.

Reminders ring on this phone. When the iOS SDK includes AlarmKit, that ring is an alarm. Otherwise it is a local notification. The words in that alert stay on the phone.

Photos and voice notes stay on the phone.
